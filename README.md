# Graphql Story API

This is a GraphQl server that let's you perform CRUD operations on a story entity.

## Steps To Run The App

1. Run "npm install" to install dependencies.
2. Create an environment named "PG_DATABASE_URL" and assign your postgresql database connection url.
3. Run "npm run migrate-db" to migrate the app tables schema to your database.
4. Run "npm run start" to start the server.
